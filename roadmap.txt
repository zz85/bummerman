Bummerman Roadmap
=================

Code Organization
-----------------
[x] ES6 modules (import/export)
[ ] Separate game logic from rendering
[ ] Event system for game state changes
[x] Config file for constants (grid size, speeds, timings)
[ ] Build system (bundler for production)

Gameplay Improvements
---------------------
[x] Start/end game screens with restart
[x] Score tracking and win counters
[ ] Pause screen
[ ] Sudden death mode (shrinking arena)
[ ] Kick/punch bombs
[ ] Remote detonation powerup
[ ] Poison/debuff powerups
[ ] Roller skates powerup
[ ] Ongoing score display during game
[ ] Dead/ghost mode (spectate after death)
[ ] Invisible mode powerup
[ ] Drop powerups on death
[ ] Time limit per round

Bot AI Modes
------------
[ ] Aggressive: prioritizes chasing players over breaking walls
[ ] Defensive: stays near edges, waits for opportunities
[ ] Chaotic: random bomb drops, unpredictable movement
[ ] Classic: mimics original Bomberman AI patterns
[ ] Difficulty levels (reaction time, perfect vs imperfect knowledge)

Animation & Camera
------------------
[ ] Player walk/idle animations
[ ] Bomb fuse particle effects
[ ] Explosion particles and debris
[ ] Death animation improvements
[ ] FPS chase cam implementation (https://www.youtube.com/watch?v=5Xe0aPNz39Q)
[ ] Smooth camera transitions between views
[ ] Screen shake on explosions
[ ] Dynamic camera zoom (track all players, zoom in/out based on spread)
[ ] Split screen view for 2 players

Maps & Scenes
-------------
[ ] Multiple themed maps/arenas
[ ] Map editor or procedural generation options
[ ] Different wall layouts and patterns
[ ] Environmental hazards (lava, ice, conveyor belts)

----------------
