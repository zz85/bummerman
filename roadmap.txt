Bummerman Roadmap
=================

Code Organization
-----------------
[x] ES6 modules (import/export)
[ ] Separate game logic from rendering
[ ] Event system for game state changes
[x] Config file for constants (grid size, speeds, timings)
[ ] Build system (bundler for production)

Gameplay Improvements
---------------------
[x] Start/end game screens with restart
[x] Score tracking and win counters
[ ] Pause screen
[ ] Sudden death mode (shrinking arena)
[ ] Ongoing score display during game
[ ] Dead/ghost mode (spectate after death)
[ ] Drop powerups on death
[ ] Time limit per round

Power-Ups (ref: https://bomberman.fandom.com/wiki/Power-Ups)
------------------------------------------------------------
[x] Fire Up - Increase bomb blast radius
[x] Bomb Up - Increase number of bombs
[x] Speed Up (Skate) - Increase movement speed
[ ] Full Fire - Max bomb blast radius instantly
[ ] Fire Down - Decrease bomb blast radius
[ ] Bomb Down - Decrease number of bombs
[ ] Speed Down (Geta) - Decrease movement speed
[ ] Pierce Bomb - Blast passes through soft blocks
[ ] Rubber Bomb - Bounces when kicked/punched/thrown
[ ] Kick - Kick bombs away
[ ] Boxing Glove (Punch) - Punch bombs away
[ ] Power Glove - Lift and throw bombs
[ ] Skull - Random disease effect
[ ] Remote Control - Detonate bombs manually
[ ] Power Bomb - Single bomb with max blast
[ ] Soft Block Pass - Walk through soft blocks
[ ] Bomb Pass - Walk through bombs
[ ] Vest - Temporary invincibility
[ ] Line Bomb - Deploy all bombs in a line
[ ] Push - Push other players

Bot AI Modes
------------
[ ] Aggressive: prioritizes chasing players over breaking walls
[ ] Defensive: stays near edges, waits for opportunities
[ ] Chaotic: random bomb drops, unpredictable movement
[ ] Classic: mimics original Bomberman AI patterns
[ ] Difficulty levels (reaction time, perfect vs imperfect knowledge)
